# Random Password Generator

**Автор:** Хаймашев Джамбулат
**Вариант:** Random Password Generator

## Описание

Программа генерирует случайные пароли. Длина задаётся в специальном поле Spinbox (можно ввести число или нажать стрелки). Поддерживаются буквы, цифры и спецсимволы. Все пароли сохраняются в историю.


## Что нужно для запуска

- Python 3
- tkinter, json, random, string

## Как запустить

```bash
python main.py
